# SITI NURBAYA — Rematri

Aplikasi edukasi anemia remaja putri (skrining, kalender haid, cadangan data).
Semua data disimpan di browser masing-masing (localStorage), tidak ada server.

## Struktur
- `index.html` — kerangka halaman
- `style.css` — tampilan
- `script.js` — logika aplikasi

## Menjalankan
Buka `index.html` langsung di browser, atau aktifkan GitHub Pages:
Settings → Pages → Source: `main` / `(root)`.
